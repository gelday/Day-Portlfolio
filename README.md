# Student Portfolio

A responsive pink, girly student portfolio made with plain HTML, CSS, and JavaScript. No framework, build step, or package installation is required.

## Files
- `index.html` — page content and section structure
- `style.css` — responsive styling
- `script.js` — mobile navigation, active section link, and current footer year

## Personalize your portfolio
Search `index.html` for bracketed placeholders such as `[Your Name]`, `[Your Course]`, and `[Project Name One]`, then replace them with your own information. Also update:
- The page title and meta description
- The profile photo placeholder (you can replace it with an `<img>` tag)
- Skills and project descriptions
- Project repository URLs
- Your email and social profile URLs

The Google Fonts import is optional. If you want the page to work without external font requests, remove the `@import` line from `style.css`; fallback fonts are included.

## Preview locally
Open `index.html` in your browser. No server is required.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `student-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish your site; the page will show the live URL in Settings → Pages.

Before publishing, replace all visible placeholders and test the navigation on both desktop and mobile.
